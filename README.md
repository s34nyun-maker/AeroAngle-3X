# AeroAngle-3X
# ✈️ ESP32-C3 Tri-Channel RC Control Surface Throw Meter
**RC 비행기 3채널(좌/우 엘리베이터, 러더) 조종면 타각(각도) 측정기**


본 프로젝트는 **ESP32-C3 (0.42" 내장 OLED 보드)**와 **3개의 MPU6050 6축 센서**를 활용하여 RC 비행기의 좌/우 엘리베이터(수평타) 및 러더(수직타)의 움직임 각도를 실시간으로 동시에 측정하는 디지털 타각 게이지입니다.

---

## ✨ 주요 기능 (Key Features)

* **3채널 동시 측정:** 좌측 엘리베이터(`L-E`), 우측 엘리베이터(`R-E`), 러더(`RUD`) 3개 타면의 각도를 한 화면에 실시간 표시 (`0.1°` 단위).
* **지능형 측정 축(X, Y, Z) 자동 선택:** 센서를 타면에 어떤 방향으로 부착하든, 날개를 `2.0°` 이상 움직이면 변화량이 가장 큰 회전축(`X`, `Y`, `Z`)을 자동으로 감지하여 측정 축으로 고정/갱신합니다.
* **러더(수직타) 완벽 대응 (3축 상보필터 + 자이로 적분):** 중력가속도 변화가 없는 수직 회전축(Yaw, 러더)도 정확히 측정할 수 있도록 가속도계와 자이로스코프 각속도 적분을 결합한 알고리즘이 적용되어 있습니다.
* **무부품 I2C 멀티플렉싱 (Software Pin Switching):** `AD0` 주소 변경 핀이 없는 초소형 4핀 MPU6050 모듈 3개를 외부 I2C 멀티플렉서(TCA9548A) 없이 ESP32-C3의 하드웨어 I2C 핀 동적 매핑만으로 개별 제어합니다.
* **원터치 영점 조절 (Zeroing):** 보드 내장 `BO0` 버튼 클릭 한 번으로 현재 타면 위치를 `0.0°` 기준점으로 즉시 리셋하고, 중립 대비 `+` / `-` 타각을 직관적으로 표시합니다.

## 🔌 하드웨어 배선도 (Pinout & Wiring)

내장 OLED와 3개의 MPU6050 센서는 **SCL(GPIO 6) 클럭 라인을 공통으로 공유**하며, 각 센서의 **SDA 데이터 라인만 GPIO 0, 1, 2번에 개별 연결**합니다.


### 핀 연결 요약표

| ESP32-C3 핀 | 연결 대상 | 배선 색상 (권장) | 비고 |
| :---: | :--- | :---: | :--- |
| **`V5`** | 1S LiPo 배터리 `(+)` (스위치 경유) | 🔴 빨간색 | 보드 내장 3.3V 레귤레이터 입력 |
| **`GD`** | 1S LiPo `(-)` 및 센서 3개 **`G`** 핀 | ⚫ 검은색 | 공통 접지 (GND) |
| **`V3`** | 센서 3개 **`V`** 핀 공통 연결 | 🔴 빨간색 | 센서 전원 공급 (3.3V 정전압) |
| **`6`** | 센서 3개 **`SCL`** 핀 공통 연결 | 🟡 노란색 | 내장 OLED SCL과 클럭 공유 |
| **`0`** | **CH1 (좌 엘리베이터)** 센서 **`SDA`** | 🔵 파란색 | `L-E` 전용 데이터 라인 |
| **`1`** | **CH2 (우 엘리베이터)** 센서 **`SDA`** | 🟢 초록색 | `R-E` 전용 데이터 라인 |
| **`2`** | **CH3 (러더)** 센서 **`SDA`** | 🟣 보라색 | `RUD` 전용 데이터 라인 |
| **`5`** | *(외부 배선 없음)* | - | 내장 OLED 전용 SDA |
| **`9` (BO0)** | *(외부 배선 없음)* | - | 내장 부트 버튼 (영점 조절 스위치로 사용) |
| **`8` (LED)** | *(외부 배선 없음)* | - | 내장 상태 표시 파란색 LED |

## 🚀 사용 방법 (How to Use)

1. **센서 부착:** 3개의 MPU6050 모듈을 각각 좌측 엘리베이터(`CH1`), 우측 엘리베이터(`CH2`), 러더(`CH3`) 타면에 부착합니다. (자동 축 선택 기능이 있으므로 부착 방향은 자유롭게 배치해도 됩니다.)
2. **전원 켜기 및 자이로 보정:** 전원을 켜면 OLED 화면에 `CAL GYRO...` 메시지가 표시됩니다. 약 1초간 기체가 흔들리지 않도록 가만히 두면 정지 상태 자이로 오프셋 보정이 완료됩니다.
3. **영점 조절 (Zero Set):** 조종기 트림과 스틱을 중립에 놓은 상태에서 보드의 **`BO0` 버튼**을 짧게 누릅니다. 화면에 `ZERO SET!`이 표시되며 모든 채널이 `0.0°`로 초기화됩니다.
4. **타각 측정:** 조종기 스틱을 움직여 타면을 `2.0°` 이상 조작하면, 화면의 `[-]` 표시가 자동으로 가장 크게 움직인 축(`[X]`, `[Y]`, `[Z]`)으로 전환되며 중립 대비 `+`, `-` 각도를 실시간으로 출력합니다.

### OLED 화면 표시 예시
```text
+----------------+
| L-E[X]: +15.4  |  <-- 좌측 엘리베이터 (X축 자동 선택, +15.4도)
| R-E[X]: +15.2  |  <-- 우측 엘리베이터 (X축 자동 선택, +15.2도)
| RUD[Z]:  -8.5  |  <-- 러더 (Z축 자동 선택, -8.5도)
+----------------+
